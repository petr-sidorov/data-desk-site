# Tool marks

- `python.svg` — official Python logo device from the Python Software Foundation: https://www.python.org/community/logos/
- `playwright.svg` — Playwright mark from the Microsoft Playwright repository: https://github.com/microsoft/playwright/blob/main/packages/web/src/assets/playwright-logo.svg
- `pandas.svg` — official pandas logo mark: https://pandas.pydata.org/about/citing.html
- `excel.svg` — Microsoft Excel green mark (2013–2019), sourced from Wikimedia Commons: https://commons.wikimedia.org/wiki/File:Microsoft_Office_Excel_(2013%E2%80%932019).svg
- `http-json.svg` and `csv.svg` — Data Desk interface symbols created for the corresponding protocol/data-format cards; they are not third-party brand logos.

The branded SVG source files are kept locally and used without recoloring or reshaping.
